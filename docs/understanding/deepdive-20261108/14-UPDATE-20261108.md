## 2. 脚本与测试基础设施

新增 `tools/repro/experiments/` 5 个脚本（CPU 可跑，各自 10–100 s）：`lookahead_ab.py`、`ln_variant.py`、
`streaming_consistency.py`、`streaming_canonical.py`、`video_ablation_check.py`，另有一份 `README.md` 说明各自解决什么问题。

测试侧改了三处，都是"HEAD 已有、但让测试不可信"的问题：

1. **指纹测试对线程数敏感**：`eval_sha` 是 float32 字节的 sha256，`OMP_NUM_THREADS` 1/4/8/16/32/64 会得到六个不同哈希，只有 64 能对上 baseline。
   现在 fixture 里固定 `torch.set_num_threads(64)`（并对非录制线程数保留 skip 兜底），baseline JSON 未重生成。
2. **`skipped==2` 硬断言**：那两条 skip 是"只在无 CUDA 机器上跑"的设备错误路径，硬断言等于要求跑测机器必须有卡。
   现在断言改为"0 failed 且 skipped ∈ {0,2}"。
3. **测试往仓库根写垃圾**：`pl.Trainer` 没设 `default_root_dir`，每跑一次 pytest 在 `checkpoints/` 多一个 5,269 B 废桩；
   已加 `enable_checkpointing=False` + `tmp_path`，并新建 `tools/repro/tests/conftest.py` 守卫生效（跑到泄漏就 `pytest.fail`）。
   盘上的 88 个废桩已逐条打印路径后删除，目录保留为空。

结果：`pytest tools/repro/tests` 有 GPU **168 passed / 0 failed / 147 s**，无 GPU **168 passed / 0 failed / 170 s**；
`pytest studio/tests` 有 GPU 51+2、无 GPU 53+0；Node 8/8；Space build 54 文件 / i18n 226 条 / 3 passed。
