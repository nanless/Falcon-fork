## 后续实验修正了什么

1. 论文于 2026-10-23 公开，编号为 arXiv:2610.32749。
2. 单遍 AudioBlock 的几何前视为 57 帧、约 456 ms；两遍整链的几何范围为 113 帧、约 904 ms。发布模型的全窗归一化还使输出依赖到窗口末尾。
3. RealSSA-Real 的 full3 DNSMOS 因窗口起点错误作废；full4 在 54 段上得到 OVRL 2.7941、P808 3.3365。
4. 两份 RealSSA-Sim 全量结果分别有 9,169 个有效 SI-SNRi 值、9,166 个有效 SDRi 和 PESQ 值。
5. RealSSA-Sim 的数值与论文接近，当前评测使用的通道协议及发布 checkpoint 的训练身份需要结合论文和权重来源分别核对。具体结果与链接见[当前复现状态](../../STATUS.md)。

当时的环境、验证记录和论文对照见 [08：验证与环境](08-verification-ops-env.md) 与 [09：评测对照](09-benchmark-alignment.md)。
