## 对 Falcon 的准备事项

- 同一表演的音频、无声视频和带音视频不能当作独立语料重复加总。
- 只有两条固定句子，不适合据此估计开放词表识别能力；歌唱不宜直接混入普通语音训练。
- 面向目标说话人提取：明确 `混合音频 → 对应目标干净音频 → 同一目标口型` 三者映射、拆分和原始说话人/视频 ID；当前数据准备完成度以实际新清单与抽检为准。
