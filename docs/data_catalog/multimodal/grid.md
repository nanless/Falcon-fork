## 对 Falcon 的准备事项

- 对齐ZIP中含一份真实文件与一份 __MACOSX/._ 伴生，若按扩展名直接数会翻倍。需剔除伴生、排除无视频说话人并做文件名交集；按说话人划分，避免同人不同句子的泄漏。
