## 内容、规模与格式

以下样本/配对/说话人数字来自 2026-10-16 的原始媒体或索引盘点；当前登记数量见上节。两者是不同时间、不同统计口径。

- 语言：英语
- 标注与格式：包内只有音频和视频；文件名含GRID式句子编码，未见独立逐句文本文件。
- 训练/测试划分：各 5,940 个 WAV 和 MOV 来自不同条件；逐条音视频配对关系待核实，训练测试需按源句和说话人隔离。
- 冷端 ASPIRE.zip 的压缩目录包含 5,940 个 WAV 和 5,940 个 MOV；这些是不同环境下的录制文件数，不能直接当作 5,940 个独立句子。
- 抽样音频为 44.1 kHz、双声道；视频为 1920×1080、30 帧/秒、无内嵌音轨。
- 发布者说明语句使用 GRID 的固定句式，目标任务是实际噪声下的视听语音增强。
- 既有下一步：适合作为小规模噪声补充或专项测试，不建议优先并入开放词表大规模主训练集。
