# 本机 Falcon 训练与测试数据：全索引和文件路径检查

检查时间：2026-11-11。这里核对服务器上已经存在的项目数据，不以冷端归档状态代替实际数据。完整结果保存在 [机器记录](07-project-resident-audit-20261111.json)，[检查脚本](audit_project_resident.py) 中保留索引遍历、路径检查、抽样解码和划分字段统计方法。

## 检查结论

共读取 **8 组、102,338 行**索引，涉及 **229,964 个不重复路径**。对每个不同路径分别执行 `stat`，本次没有缺失或访问错误。这里的“路径检查”验证路径在检查时可访问；它不是对全部媒体逐个解码或重新计算内容哈希。

每组另外取首条、约四分之一、中间、约四分之三和最后一条：共 **40 组索引位置**，实际解码其中的混音与目标音频；各组首条额外读取嘴部张量。所有抽样音频均可读、采样值有限，8 份嘴部张量可读取。LRS2 六组的这些抽样中，`mix − target − near` 的最大绝对误差均为 **0.000030517578125**，相当于一个 PCM16 量化单位；这一波形关系是抽样结果，不是全量波形校验。

路径与读取字段：

- 单方向 LRS2：`/root/data/falcon_lrs2_2mix/{tr,cv,tt}`。混音、目标及嘴图在转换目录，near 指向源数据对应的 `s2`。
- 双方向 LRS2：`/root/data/falcon_lrs2_2mix_paper/{tr,cv,tt}`。混音与目标多指向 `/root/data/lrs2_2mix/lrs2_rebuild/audio/wav16k/min/`，嘴图在 paper 目录。
- RealSSA：`/root/data/falcon_realssa_sim/tt` 与 `/root/data/falcon_realssa_sim_ch0/tt`。两组每组 9,169 条 near 都与该行 mix 路径相同；它是占位，不是独立干扰说话人录音。

所有 8 组的索引行均未发现 mix/target 文件名不一致、索引采样点不一致或 near 条目数不为 1 的情况。这些检查验证索引结构和名称，不自动验证目标说话人身份与嘴型同步。

## 样本音视频形状

LRS2 六组各抽 5 条混音和目标音频，均为 **16 kHz、单声道、32,000 采样**；每组首条嘴图为 `torch.uint8 [50,96,96,3]`。RealSSA 两组各抽 5 条，均为 **16 kHz、单声道**，采样长度依次为 92,800、77,440、94,080、91,520 和 24,320；各组首条嘴图为 `torch.uint8 [145,96,96,3]`。RealSSA 原始四通道数据与场景元信息见[项目训练和测试数据](01-project-data.md)。

## 划分之间的文件名字段

LRS2 单方向和双方向全部混音文件名均匹配项目现用的两路编号和增益格式。脚本分别提取两路名称中的**首段数字字段**及**首段数字＋片段编号组合**，统计 tr/cv、tr/tt、cv/tt 三对交集，结果都为 0。混音两路均参与统计。

这些数字来自文件名解析；目前没有在本项检查中将它们和独立的原视频或说话人身份表逐条关联。因此结果说明解析出的文件名字段在三组中没有重叠，不能单独证明说话人隔离，也不能排除不同标识对应同一人物或内容。音视频实际时间对齐、人物身份和跨数据集重复仍需要按具体实验继续核对。

审计初版把这两个计数标签写成了 source-video 和 utterance；为避免超出证据含义，机器记录现标为 `filename_first_id` 和 `filename_id_plus_segment`，数值没有变化。[原标签重建记录](07-project-resident-audit-original-labels-20261111.json)保存了修正前的字段和数值，供追踪；它是根据当次结果重建的原标签版本，不是逐字节原文件副本。

## 重复检查

```bash
cd /root/code/github_repos/Falcon-fork
OUT=$(mktemp -d /root/tmp/falcon-resident-audit-XXXXXX)
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 /root/miniforge3/envs/falcon/bin/python \
  docs/data_catalog/audit_project_resident.py --output "$OUT/audit.json"
```

脚本通过 `--output` 独占创建新 JSON；示例输出在新建的临时目录，已有记录不会被覆盖。本次单进程索引与 229,964 路径检查约 134 秒；耗时会随文件系统状态变化。完整数据访问、训练协议及现有结果见 [项目数据总览](01-project-data.md)。
