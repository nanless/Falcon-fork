# 120 ms 子带估计与双卡训练准备

上一轮的开源有限历史探针表明，开源模型只读当前块和上一块，在同一批 24 条开发样本上仍比旧流式模型高 0.71 dB。开源模型的 240 ms 音频路径中位数为 105.55 ms。v8 在现有流式主干上加入约 6,376 个参数的子带细化层，用共享卷积对当前块内的相邻时间与频带建模。已有视听主干特征参与调制，输出有符号频响残差。新输出层零初始化，热启动与旧输出逐采样一致。正式配方保留原主干的因果状态，关闭额外历史注意力。

[训练配置](../../configs/RealSSAStreamingSubband.yml)使用双 A800，每卡 64 条、全局 128 条，AdamW 目标学习率 3e-5，预热 100 步。训练恢复按轮变化的时间裁剪和嘴图增强。派生 tr 与完整 cv 分别有 80,205 和 10,828 条，目标视频目录互斥。热启动用旧第 114 轮权重，此权重训练时已接触官方 tr，派生验证用于配方检查和选点。历史官方 TT 按旧训练与验证的目标路径和母视频目录分层后，三层质量差距均约 3.4–3.5 dB。目标目录和目标路径均未见的层仅有 32 条。

训练使用干净目标的重建损失和三分辨率复数 STFT 辅助项。辅助项按目标响度归一化，保留输出幅度和相位误差，退化目标沿用原归一化 MSE。对 64 条固定样本，低权重短训将输出对目标的投影中位数从 0.547 提高到 0.589，目标归一化 RMSE 从 0.538 降至 0.516。权重 4 的投影中位数为 0.623，目标归一化 RMSE 为 0.498，最优增益对齐后的误差基本持平。

## 训练梯度修正

按原双卡采样器重放高梯度批次。第 143 步的一条低能量有效目标与输出近乎正交，原 SI-SDR 波形梯度范数约 12,810，同一输出的谱损失梯度约 2.92。训练目标对 SI-SDR 的线性功率比加入 0.001，再取对数。原指标和退化分支保持其计算定义，完整验证仍以原重建指标选点。

同一 180 步双卡重跑中，裁剪前参数梯度范数从最大 403.60 降到 81.26，P95 从 95.44 降到 25.09。第 49 步从 403.60 降到 8.82，第 143 步从 316.37 降到 9.34。全局裁剪阈值仍为 5。独立回归验证默认目标、退化分支、验证指标和严格续训设置。

修正后相对同权重未修正版的配对均值为 +0.01157 dB，按 210 个目标视频目录重采样的 95% 区间为 [+0.00050, +0.03101] dB。相对热启动旧权重为 −0.00553 dB，区间 [−0.02560, +0.01354] dB。这一组只运行 180 步，完整训练后的质量由验证选点和官方测试评估。

实音视频的后续块扰动回归覆盖音频、嘴图和会话状态。正式启动脚本会核对短跑、源码和配置摘要，并要求该短跑权重的 500 个 CPU 块逐块低于 60 ms。使用已预裁嘴图和 4 个 CPU 线程，计时包含嘴图归一化、模型、状态与输出复制。 修正后权重的实测 P50 为 16.54 ms，P99 为 19.39 ms，最大 20.73 ms，500 块无超限，计划释放到完成的最大值为 20.79 ms。四个独立的跨块音频和视频扰动前缀误差均为 0。
