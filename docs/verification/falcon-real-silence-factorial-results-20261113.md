# Falcon 响度增强与真实静默监督的四组结果

四组固定发布 Small 的滚动模型、600 ms 历史、120 ms 输出、80 ms 前视。每次输入原混音和指定目标嘴轨，输出一路。每臂 96 步、每步 8 个请求、同一初值和优化器。四组共用 120 个 LRS2 训练混音及真实会话训练窗。静默关闭组也读同一批真实嘴图和混音，静默行的梯度为零，分母和有声保护行相同。响度开关只改预先固定的 LRS2 混音槽，两个目标请求读同一混音。详细见 [训练协议](falcon-rolling-real-silence-ab-20261113.md) 和 [训练语料](falcon-roomreader-native-silence-data-20261113.md)。

SI-SDRi 是相对原混音的改善，越高越好。静默分数是输出能量相对原混音，越负越好。重新开口的目标拟合能量变化越接近 0 越好，参考是原混音内同一目标的拟合能量。开口拟合和语音 SI-SDR 衡量不同问题。19 条开口头 120 ms 的 SI-SDRi 为 −6.25／−5.42／−5.51／−4.73 dB。四组均低于原混音。联合组最差目标能量变化 −67.24 dB，且这一段总输出能量相对原混音降约 50 dB。这里只量化起头削弱，未做听辨词级漏字率。学生目标的 15 条敏感性子集保持同一方向，首 120 ms 的目标拟合变化为 −13.24／−21.29／−15.21／−25.82 dB。详见 [重开口协议](falcon-roomreader-reopen-20261113.md)。

## 因子各自的作用

- 响度增强在两种静默设置下均使受控 ±12 dB 双极性成功多 4 对。RoomReader 真实弱目标在静默关闭时掉 6.22 dB，在静默开启时掉 1.52 dB。开口头 120 ms 的目标能量分别多损失 6.67 和 7.77 dB。仅学生的真实弱目标子集上，四组仍高于原混音，响度增强相对各自的关闭组依然更低。
- 真实静默监督单开时，三个数据集的固定静默均值相对都关分别变化 −1.59、+0.46 和 +1.97 dB。联合时，在响度增强组之上分别再降 7.84、12.04 和 6.86 dB。联合组仍无法压住开口前的最坏段。EasyCom 和 MISP 是整套独立语料复核。RoomReader 训练与评分的会话及指定学生不重叠，共用教师在训练窗内无人工标注活动，且其个人轨能量至多为混音的 −43.83 dB。
- 真实重叠没有一个组在两套含参考轨的录音上都领先。MISP 只有一场、无同步近讲波形。联合组相对两输出均能量的换嘴差为 −1.45 dB，表示输出对换嘴更敏感，无法独立确认目标归属。

四组为单种子、固定范数 5 梯度裁剪短训，384 次更新均有限且全部触发裁剪。真实可见静默监督的开关具有明确对照，当前数据量和短预算仍不足以确定效应跨种子稳定。原始数据臂以外的三组均未同时解决弱目标、真实静默和开口保真。后续可从响度增强的剂量和明确开口监督两点分开验证，验收同时记录开口前最坏漏音和开口后目标保留，至少复测一个种子。
