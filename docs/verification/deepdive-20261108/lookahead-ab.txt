## 结论（全部实测）

1. **默认配置与发布权重逐位相同**：`default` 输出 sha256[:16] = `ad0532a6e994921f`，`torch.equal` 对自身 = True；`strict=True` 装载 525 个 audio key 成功。
2. `paper_causal=True` 改变输出：max|Δ| = 1.301e+01（**不是**逐位相同）；局域前瞻从 2 帧降到 0 帧；端到端「看未来」帧数几乎不变（125.0 → 125.0）。
3. `video_lstm_batch_first=True` 改变输出：max|Δ| = 1.295e-02；扰动第 25 帧后 VideoBlock 受影响帧数 1 → 7（>1e-6·max 口径 1 → 5，递减到 float32 下溢即停），即默认配置**帧间完全没有递推**。
4. 两者同开：max|Δ| = 1.301e+01。
5. 单窗耗时：default 429 ms / paper_causal 428 ms / video_lstm_batch_first 432 ms / both 457 ms。
6. 所以这两个开关**只修几何，不修归一化**：要让模型真正无视未来，还得动 `cLNhw`（见 `ln_variant.py`）。
