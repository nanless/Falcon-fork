# RoomReader 可见静默训练样本的来源与校验

本轮固定原发布会话混音、同场目标个人麦和指定人的同步视频。每条 2.88 秒，按 16 kHz 单声道与 25 fps 嘴图对齐。选中的块具有 600 ms 音频历史、120 ms 当前块和 80 ms 前视，所有上下文帧都有实际嘴图。目标声学参考用个人麦乘以其拟合原混音的增益。原混音始终直接读取发行 WAV。

静默块要求目标无人工校订语句、词级时间或副语音标注，额外留 80 ms 保护，并有至少一名非共享人员在说话。每个保留的静默块都复核个人轨与原混音的能量比。发声块要求目标词级时间戳与校订语句同时有效、排除副语音，并通过个人麦能量筛选。

| 核验项 | 结果 |
| --- | ---: |
| 正式缓存 | 26 条，5 场，14 个指定目标 |
| 每场条数 | 6、6、3、6、5 |
| 合法静默块 / 发声块 | 143 / 110 |
| 按最终能量筛选后的时序统计 | 停口 13，重开 9，停口后重开 4 |
| 最响的静默目标个人轨，相对原混音 | −29.38 dB |
| 最响的共享教师个人轨，相对原混音 | −43.83 dB |
| 原混音最小二乘拟合残差 / 原混音功率上界 | 3.89% |
| 嘴图时钟最大绝对偏差 | 6.67 ms |

选样窗口与盲评的五场无交叉，指定学生与盲评参与者 ID 无交叉。RoomReader 跨场复用两名老师，无法在原始会话名单上实现人物完全互斥。保留的训练窗内，共享老师没有官方发声或副语音标注，且其个人轨满足上述能量检查。MISP 和 EasyCom 未用于本轮训练，可作为另来源验证。

服务器实际正式清单为 `silence_factorial_20261113/data/checked/manifest.json`，SHA-256 为 `995b8e2d0e53b2b0e36747f8ce767ee228b3f6532767a5d37fd5ed4195c5d8e3`。原始生产脚本 SHA-256 为 `ab34439f2c6a67a4fdaee4e3cbee2086584df606f487a408f0184125dd05beba`。额外逐块证据清单 `frozen-first21-plus.json` 实含同序同哈希的 26 条样本，增加静默目标能量数据。运行日志记载 9 个 WAV 读取异常，均被跳过。缺视频、嘴图不连续或能量不符合的候选也会被跳过，原日志未逐类统计这些正常筛除。初版静默转移名称在最终能量筛选之前写入，复算有一条从“停口后重开”归为“重开”，上表使用最终合法块，训练读取的是块标签。

复现使用 `python -m tools.streaming.prepare_roomreader_silence --source DATASET_ROOT --face-model FACE_LANDMARKER --output NEW_DIRECTORY --sessions S08 S10 S17 S20 S23 S27 S29 S30 --count 26 --per-session 6`。本轮使用 MediaPipe 0.10.32。脚本输出媒体派生缓存、内部逐条身份清单与哈希，均保存在授权服务器。RoomReader 限非商业研究，外部报告只使用聚合结论并引用原论文。[RoomReader 授权说明](https://sigmedia.tv/datasets/room_reader/) · [原始论文](https://aclanthology.org/2022.lrec-1.268/)
