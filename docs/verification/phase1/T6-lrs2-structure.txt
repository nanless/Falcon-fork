## 3. 音频：split / 命名 / 2 s / 16bit / 8k 版本
wav16k/min/{tr,cv,tt}/{mix,s1,s2}: tr 20000 / cv 5000 / tt 3000（各目录同样数量；共 28,000 组）
wav8k/min/{tr,cv,tt}/{mix,s1,s2}:  同上（8 kHz 版本，与 16k 一一对应）
文件名：<id1>_<snr1>_<id2>_<snr2>.wav；snr2 = -snr1，snr1 ∈ (0,5]（28000 条全部可解析；|snr| mean≈2.504）
样例：5535415699068794046_00004_2.4022_6160231649911868423_00015_-2.4022.wav
格式：16 kHz 或 8 kHz、mono、PCM_16、**恰好 2.000 s**（16k=32,000 样本；8k=16,000 样本）
验证：随机 tr/cv 各 100 + tt 全部 3000 个 mix 均 2.000 s / 16 kHz / 1ch；mix == s1+s2（20/组×3 split，max|Δ|=3.05e-5，纯 16bit 量化）
split 无泄漏：tr→raw train（18,691/19,649 ids）、cv→raw val（476/476）、tt→raw test（267/267）

## 5. 混音/参考重建（MATLAB 原逻辑，create_mix/create_wav_2speakers.m）
1) 读 raw wav → 8k/16k：s1_16k = weight1*s1/sqrt(lev1), s2_16k = weight2*s2/sqrt(lev2)，
   weight=10^(snr/20)，(lev1,lev2)=activlev 归一化因子；min 模式按较短长度截断；
2) mix = s1+s2；取 max_amp=max(|mix|,|s1|,|s2|)，同一 mix_scaling=0.9/max_amp 乘到 s1,s2,mix；
3) 写 s1/s2/mix 的 PCM16 wav；scaling.mat 保存 scaling_16k(N,2) 与 scaling16bit_16k(N,1)（8k 同）。
实测 mix == s1+s2（16bit 误差内）→ **s1/s2 已是精确的 scaled target 参考，无需再从 raw_audio 重建**；
若需重建 target（例如换目标说话人 convention），用 create_wav_2speakers.m 公式 + scaling.mat 可逐样本精确复算。

## 7. 对复现的含义
- LRS2-2Mix 已是**完整 2 s AV 数据**：mix/s1/s2（16k+8k）+ mouths + faces + landmarks + 混音脚本与清单；
  不需要 LRS2 原始视频即可做 LRS2-2Mix 的 AV 训练/评测（旧计划“无视频/嘴部”的结论需更正）。
- 构建 Falcon folder 数据：mix 取 `audio/wav16k/min/<split>/mix/*.wav`，target 取同 split 的 `s1`（或 `s2`，需固定 convention）；
  mouths npz → `.pt`：`torch.save(torch.from_numpy(np.load(npz)['data']).unsqueeze(-1), id.pt)` → uint8 [50,96,96,1]，
  以匹配 load2hear loader 的 `.permute(0,3,1,2)`；JSON 索引用 DataPreProcess/process_lrs23.py；near 源不存在（用 use_near=false 或替代负样本）。
- 评测：tt 3,000 组，全部 2.000 s → 模型输入窗口=整句（window=2 s），可直接按 clip 计算 SI-SNRi/SDRi；
  固定 target convention（s1 或 s2）并在报告声明。
- 许可：tar 内含 LRS2 派生 faces/mouths/音频，受 LRS2（BBC 来源）与源视频条款约束；HF 卡片的 apache-2.0 标签不能覆盖源数据条款；**不得再分发**。
- 空间：压缩包 16.47 GB + 解压 17.39 GB；建议预留 ≥40GB（含转换后的 2mix 副本，保守 60GB）。
