# Falcon 流式选人退化的定位与修复

2026-11-13，A800。任务是单声道混音和指定目标的 25 fps 嘴部轨迹输入，输出一路目标语音。干扰人数可变。每 120 ms 交付一块，输入前视为 80 ms。

## 选人失效的定位

LRS2 CV32 在训练前已冻结。按真实响度、响度差、重叠程度分八组，每组四个混音。每个混音固定音频、分别用两套嘴图。两个输出都比另一源更接近各自目标才算选对。同一测试内参考和有效区间一致。

| 模型 | 两个方向均正确 | 目标 SI-SDRi |
| --- | ---: | ---: |
| 发布 Small，整段 | 29/32 | +6.915 dB |
| 发布 Small，仅重算可用前缀 | 26/32 | +5.723 dB |
| 发布 Big，整段 | 28/32 | +7.679 dB |
| 发布 Big，仅重算可用前缀 | 26/32 | +5.978 dB |
| 120/80 历史架构，已隔离坏源的 step 1375 | 3/32 | −0.522 dB |
| 发布 Small，600 ms 滚动历史、缓存视觉 | 27/32 | +4.619 dB |

发布权重前缀每块重算从开始到当前块尾加 80 ms。滚动入口只使用固定历史、三帧当前视觉特征和两帧前视，重算可用音频窗。这两种运行方式的上下文及波形边界不同。发布模型的整窗归一化及非流式内部计算仍存在，输入截窗落实前视预算。

固定另外 12 对，只改变同两路源之间的相对响度、保持嘴图和说话内容，合成后用共同增益控制混音 RMS。A 强 6 dB 时，两个输出都偏 A 的是 12/12。B 强 6 dB 时，全部跟着偏 B。零增益重合成前后双向正确均 1/12。分层 CV32 在两个 6 dB 极性上同样均为 0/32 双向正确。这个反事实直接验证了当前权重的响度依赖。逐层测得的视觉变化从瓶颈后 68.6% 降至高分辨率融合后 20.7% 和掩码 11.5%，属于结构线索。提前或末端加门的小试没有带来稳定的留出收益。

## 有界训练

同一已保存权重、120 条训练混音、同一抽样次序、每步四个混音的两个真实方向、每臂 96 步。冻结发布视觉前端。母视频目录在本次训练与验证清单间无交叉。自然响度双向训练在留出从 3/32 到 11/32，轮换 0、+6、−6 dB 的训练臂到 15/32。两臂均在 ±6 dB 条件为 0/32，整体 SI-SDRi 均约 +0.22 dB。在第二次实验，额外拟合真实目标差波形让平均选择差扩大，但自然响度仍 13/32，±6 dB 的 SI-SDRi 变差。现有短训未解除响度捷径。

## 滚动候选

`tools.streaming.rolling_falcon_live.RollingFalconLiveInference` 读取发布 Small 权重，复用 40 ms 会话协议。默认保留五个已提交块，最多重算 800 ms 音频窗。每次提取三个已具备全部上下文的嘴部特征，未来两帧仅用于生成当前特征。当前窗预览位置使用最后一个已计算特征。状态只保留已提交音频和视觉数据。

```python
from tools.streaming.rolling_falcon_live import RollingFalconLiveInference

stream = RollingFalconLiveInference("/root/.cache/falcon_weights/falcon.pt", device="cuda")
blocks = stream.push(audio_40ms, normalized_mouth_88x88, sequence=0)
# 连续提交后续 tick，流结束时调用 stream.finish()。
```

采集或跟踪层确认该 tick 没有目标嘴图时传 `None`，该 tick 输出静音并保留时钟。目标仍在画面却未发声属于另一场景，需测量真实泄漏。传全零图像仍是有图输入。在 16 个受控无有效嘴图的方向，之前把零图当有效输入会留下相对混音平均 −6.93 dB 的能量。传入明确缺失信号后，同 16 个方向的返回波形均为零（评测下限 −120 dB）。目标轨迹在每个会话固定，换目标时重开会话。

冻结 32 对的 600 ms 历史试验共 1,088 个块。A800 单路同步处理 P50 44.49 ms、P99 51.75 ms、2 块超过 60 ms，最大 114.78 ms。计时包括核心视觉、音频重算及同步，未计采集、网络、推理排队或下游播放。初次测试使用逐位判定失败，第二次固定 cuDNN 确定性并记录数值差。改变前视范围以外的音视频后，前 240 ms 输出峰值差为零。

受控零／一／二干扰实验固定每个方向的目标波形和嘴图。二干扰组加一条独立母视频的语音，合成后使用共同防削波增益。滚动候选在 16 个方向的平均绝对波形 SNR 为 20.28／7.30／4.23 dB，一／二干扰目标优于每个干扰源均为 15/16。四步历史候选对应 15.82／1.93／0.18 dB，目标胜出 8/16 和 4/16。受控三人合成覆盖当前假设，真实三人及以上、可见但不说话、错轨、跟踪丢帧和长流恢复仍需独立验证。

额外使用冻结的 24 条 RealSSA-Sim CV 比较原生逐 tick 入口和历史 120/80 候选，在相同目标有效区间评分，滚动候选平均 SI-SDRi +5.884 dB，历史候选 +2.892 dB。滚动入口在 2 秒验收边界 flush，历史候选沿旧协议可读切片后有真实预览的部分。该组均为有效语音目标，来源与官方训练有重叠，不能用于证明来源独立的泛化。
