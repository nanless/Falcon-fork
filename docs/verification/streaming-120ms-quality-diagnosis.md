# 120 ms 流式模型与开源 Falcon 的质量差距：逐项诊断

## 研究对象和主要结论

固定训练中第 100 轮、4,900 次更新的 320 通道 v4 检查点，在 RealSSA-Sim 官方 tt 上与公开 Falcon 做同样输入的配对测试。9,169 条均遍历，其中 9,166 条目标有效：开源模型平均 SI-SDRi **7.731 dB**，新模型 **4.247 dB**，差 **3.485 dB**。详细身份、样本覆盖和三个全零目标见[完整评测记录](streaming-120ms-realssa-tt-epoch100.md)。

这里的改造并非只改变分块：新模型的音频结构、输出表示、历史状态、训练目标、批次与优化更新次数都与开源路径不同。开源 Falcon 观察整段 2 秒，新模型只使用当前 120 ms 块和历史。多个因素同时变化，不能把 3.485 dB 直接归给某一个因素。

已证实的问题包括：训练专用说话人对比头后期表征高度集中、其相对于重建项的梯度变小；全零目标的 SI-SNR 重建分支没有梯度；流式输出存在可测的块边界跳变；当前检查点选择的 0.01 阈值使其不一定保存数值上最小的验证损失。它们的量化证据和范围如下，现有实验不能将这些现象的分值简单相加。

## 一、先核查评测是否把差距算大

- 固定随机测试 128 条并覆盖全部 19 个分片；再取其中间隔样本 64 条，比较原始 TAR loader 与历史转换文件，按相同中心起点和补齐重建混音、目标、88×88 嘴图，三者的最大绝对差均为 **0**。这核对了样本读取与转换，不等于验证原始采集中的声画同步。
- 开源整段模型在同一 64 条上的 CPU/GPU 平均 SI-SDRi 分别是 **7.64430 / 7.64445 dB**，最大单条差约 0.0116 dB；数值设备差异不能解释全量 3.485 dB。
- 上述 64 条有 12 条短于 2 秒，比较同一预测在补零后 2 秒与有效时长上的分数，两模型平均差距变化约 **0.00072 dB**。这一检查只覆盖这 12 条。
- 按既有匿名目标源路径审计将 9,166 条有效测试样本分组：目标源路径存在于训练集的 4,582 条，新模型与开源模型的平均差为 **-3.458 dB**；目标源路径未出现在训练集的 4,584 条，差为 **-3.512 dB**。目标路径不同不能证明说话人独立，且两组不是随机干预；这只说明两组中均存在差距。
- 四类场景的平均差均存在：室外 **-4.461 dB**，中型室内 **-2.964 dB**，大型公共空间 **-3.311 dB**，小会议室 **-3.171 dB**。这些分组在该数据中高度混杂：室外样本全部落在 RT60<0.3 秒，大型公共空间全部落在 RT60≥1 秒，小会议室的远场干扰数量全部为 0，其他三类均为 10–15；不能由此将差异单独归因为场景、混响或远场干扰数量。

RealSSA 官方 tr/tt 有已记录的目标源重叠；这些 tt 样本现在也已用于诊断。保留官方 tt 以便比较，并为下一轮模型选择另设按已知源隔离、尽可能确认说话人身份的验证和测试划分。

## 二、120 ms 任务比整段任务约束更多

固定 64 条测试样本，两个模型分别使用相同的混音、目标、嘴图和 2 秒 SI-SDRi 计算：

| 模型和输入 | 平均 SI-SDRi |
| --- | ---: |
| 开源 Falcon：整段 2 秒 | 7.644 dB |
| 开源 Falcon：独立 480 ms 窗 | 5.814 dB |
| 开源 Falcon：独立 120 ms 窗 | 2.625 dB |
| 新流式模型：120 ms 块，保留历史 | 4.279 dB |

开源模型未按 120 ms 窗训练，独立小窗还会重复重置模型状态和窗口边界；这些变化混在一起，不能把下降的 5.019 dB 全部当成纯粹的因果延迟代价。该对照证明直接把开源模型切成独立短窗会退化，新模型在此对照中受益于自己的训练与历史缓存。

同 64 条，若只清零新模型每块的音频卷积缓存，保留音频重叠和视觉缓存，均值从 **4.279** 降至 **3.253 dB**；全部状态每块清零降至 **2.802 dB**。清零不属于训练时的常规状态，但表明模型确实使用跨块历史。

## 三、视觉输入有效，但预训练前端的时间窗口被改变

128 条同样的输入中，流式模型使用真实嘴图为 **4.139 dB**，使用错配样本嘴图为 **-1.009 dB**，使用归一化后的零图为 **0.865 dB**。错配按固定偏移选其他样本，原始目标文件和父目录不同，未核实不同说话人；这些结果说明视觉输入确实影响新模型输出。开源模型对应真实/错配分别为 **7.500 / -3.466 dB**。由于两者上下文不同，不把两个真图减错图的差直接当成等条件唇动利用能力差。

原 FRCNN 前端使用对称 5 帧时间窗口；新模型为了块间因果改为 4 帧历史加当前帧，且冻结前端权重。16 条视频、相同权重、关闭 TF32 的实测中，原前端特征 `ref[t]` 与新前端 `causal[t+2]` 在有效位置逐元素相等，表明特征窗口中心相对时间标签相差 **2 帧/80 ms**。

不能把这点直接等同于 80 ms 的可修复错位：同一组 64 条上，全序列把视频相对音频移动 -80/-40/+40/+80 ms，均值分别比原对齐下降 **1.845/0.399/0.267/1.617 dB**。正方向在离线实验中使用未来视频，不能直接用于当前因果接口；训练后模型已适应当前输入时间关系。可在新实验中重新设计块内可见的视觉上下文、视觉蒸馏或允许前端适配，并重新训练，不能简单平移已训练模型输入。

## 四、说话人对比正项后期退化

当前 [训练器](../../tools/streaming/train_ddp.py#L108)将输出与目标经共享投影和训练专用池化头编码，目标分支停止梯度；调用对比损失时传入的近场负样本均为 `None`。公开 RealSSA-Sim TAR 没有逐个对齐的近场干扰人波形，现有训练不是论文完整的正负对比目标。

同一批固定 48 条验证片段，正确输出与目标向量在 48 个候选目标中按余弦相似度检索：

| 检查点 | 正确配对 top-1 | top-5 | 平均排名 |
| --- | ---: | ---: | ---: |
| 初始化 | 14/48 | 25/48 | 10.52 |
| 第 1 轮 | 23/48 | 33/48 | 6.96 |
| 第 25 轮 | 8/48 | 22/48 | 9.27 |
| 第 50 轮 | 11/48 | 28/48 | 8.54 |
| 第 75 轮 | 4/48 | 10/48 | 15.85 |
| 第 100 轮 | 3/48 | 11/48 | 18.17 |

随机排列的 top-1 期望为 1/48，平均排名为 24.5。48 条目标原始文件路径和父目录各不重复，但未完成人工说话人身份核实；这不是 48 名不同说话人的确认结果。该指标是对训练专用头的配对检索，不是整套模型的说话人识别准确率。

第 100 轮，不同目标向量两两余弦均值为 **0.98784**，输出对正确目标的均值 **0.99485**，对其他目标 **0.99221**；高相似度和正确检索排名后期下降共同支持表征趋同，但不能说完全没有区分力。固定 4 条片段上，重建和正项单独反传的全参数梯度范数分别为 **61.48** 和 **0.144**，正项约为重建项的 **0.23%**。这是该小批次、该检查点的局部测量，不能直接给出全训练过程的因果贡献。

下一步应做受控对照：同初始化、同数据与计算预算比较纯重建、现有正项、具有可验证身份/来源约束的对比或冻结说话人表征；不能把来源不同直接视为说话人必不同，也不能把混音减目标的聚合噪声当作论文的逐个近场负样本。

## 五、零目标、边界和实现效率

**零目标。** 验证集 9,133 条目标完整解码，2 条四通道整段严格全零；训练集固定种子随机抽取 4,096/100,826 条，1 条四通道整段全零。训练抽样数不能外推为全量零目标数量，也未覆盖原音频非零但随机裁剪为静音的情况。实测 [pairwise_neg_sisdr](../../look2hear/losses/matrix.py) 对零目标的重建损失为 **+80**，预测梯度为 **0**；这只描述重建分支，不表示整个训练目标所有分支均无梯度。验证集这两个固定条目使全量均值相对排除它们后的均值上移约 **0.0186**；偏移量随其余样本均值略有变化。只要每轮均包含这两个固定的 +80 值，两种均值之间是固定的线性关系，保留轮次排序，但数值差不完全相同。应为静音目标设计显式输出能量/静音损失，分别报告有效数，并保持原始分母记录。

**块边界。** 64 条测试中，120 ms 块边界相邻采样跳变与附近采样跳变之比：新模型 **1.501**，混音 **1.016**、目标 **0.987**、公开 Falcon **0.988**；8 ms hop 边界也有较小差异。对新模型做不看未来块的单边平滑，块边界 4/16/32 个采样宽度的平均 SI-SDRi 分别变化 **-0.0028/-0.0101/-0.0226 dB**；简单平滑没有解决分差，是否可闻需听测。后续应优先检查输出连续性、状态和训练损失，而非直接加平滑。

**输出形式。** 新模型的每跳输出为 0–1 实数掩码，经因果 FIR 重建，仍能形成相位变化；不能简单说“完全不能改变相位”。16 条样本中，允许逐跳独立优化并读取干净目标的受限掩码 oracle 平均 **14.885 dB**，实测模型 **3.903 dB**、公开 Falcon **8.118 dB**。该 oracle 泄漏目标及整段信息，也不保证全局最优；oracle 脚本的 SI-SDR 数值稳定项与正式评测函数位置略有不同。该实验说明在这些样本上当前输出形式有更高可表达解，不能证明可部署模型能达到该分数，更不能把现有 4 dB 直接称为该输出层硬上限。

**训练效率。** [现有正项实现](../../look2hear/losses/nass_contrastive_loss.py#L52)逐样本 Python 循环。batch 1024、64 维、非空批次且全部无负样本、目标停止梯度的隔离测试中，循环与批量余弦均值的梯度最大绝对差为 0、损失差小于 3e-7；共享 GPU 上前向加反向中位耗时分别约 **370 / 0.45 ms**。这是单个算子而非整轮训练测速，不能据此宣称整网加速 800 倍；负样本、权重或空批次改变时需另行处理。

**优化次数和检查点。** 每卡 1024、两卡不累积对应全局 2048；第 100 轮约 4,900 次参数更新、约 1,003.52 万个 2 秒样本曝光。相同曝光量下 batch 32 会有约 64 倍的更新次数，但这不是控制变量实验，不能据此断定当前主要质量瓶颈；发布权重的完整训练履历亦未确认。已记录的 5,380 次更新中，预裁剪梯度范数超过 5 的有 85 次，约 **1.58%**；这一比例不支持把频繁裁剪直接当主要解释。

在截至第 109 轮的检查中，`min_delta=0.01` 同时用于“明显改善”与最佳检查点更新，因此第 108 轮验证损失 **-5.033191** 虽数值低于选中的第 100 轮 **-5.023486**，仍未替换 best。同一 TT 随机128条上，第100/108轮分别 **4.13905/4.13748 dB**，两轮差约 **-0.00158 dB**；这里没有证据支持检查点阈值造成 3.485 dB 差距。第 111 轮后来降至 -5.034234，达到阈值并更新 best；同一 128 条上的第 111 轮均值为 4.13862 dB，比第 100 轮低约 0.00044 dB，这个小样本不支持“只要换较新检查点就消除差距”。下一版应分开保存数值最低的检查点和用于早停的显著改善计数。

## 已训练权重的 CPU 检查

固定第 100 轮权重，在双卡训练并行运行时，使用 Xeon 8336C、4 个 PyTorch 线程、20 块预热后按 120 ms 节奏测试 500 块：处理耗时 P50 **23.55 ms**、P95 **29.69 ms**、P99 **32.77 ms**、最大 **35.93 ms**；500 块均小于 40 ms。计划释放到完成最大 **36.01 ms**。计时覆盖嘴图预处理、视觉和音频模型、状态处理及输出复制，不含采集、检测跟踪、网络和播放。输入来自单条 LRS2 真实样本的 16 块循环，循环边界是合成的。记录为 `diagnostic_tt128_visual_epoch100/trained100_cpu4_paced500_concurrent.json`；这一测试证明所测条件下达标，不替代收敛权重和其他负载条件的独立复测。

## 后续验证顺序

1. 在不改动正在运行的训练及其严格续训协议的前提下，保存当前实验作基线；收敛后对所选权重完整测试，并用已训练权重复测 CPU 120 ms 块耗时。
2. 在独立实验中修复零目标处理，区分真正静音和语音片段，先验证损失与梯度，再报告各类样本数。
3. 固定数据、块长、模型和评测条件，比较纯重建、当前正项、可靠负样本/固定说话人表征；记录 embedding 检索、目标/干扰说话人身份和质量，避免错误负样本。
4. 做满足块间因果的视觉上下文及边界结构 A/B；对 120 ms chunk 的所有 future-chunk 干预复跑因果性测试，再测包括视觉的 CPU P95/P99、最大值。
5. 以相同输入、相同训练曝光和更新预算分别比较不同 batch、网络容量、输出头。保留官方测试协议用于复现，同时另设未用于本轮诊断的源隔离评测。
