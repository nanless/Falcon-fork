# 真实录音上的结构与数据四组短训对照

2026-11-13，四组从同一发布主干和相同输出起步，共用 120 个训练混音、96 次更新、600 ms 滚动历史、120 ms 输出和 80 ms 前视。每次只根据一个指定嘴轨输出一路语音。训练选窗、数据替换和受控 CV32 见 [四组训练协议](falcon-rolling-factorial-ab-20261113.md)。

新结构保留发布网络早期音视频融合，在复数掩码之前加一条按时刻、八个频带及八组通道的直接嘴型调制，新增 20,640 个可训练参数，约为基础训练参数的 3.95%。本轮结构效应包含这一分支和新增参数量。两个数据臂比较的是响度反事实和可见低活动置零的组合。每臂只跑一个种子，不能据此分开两种数据变化的贡献。

## 四组实测

双极性成功要求固定两位说话人，轮流让每位比另一位响 12 dB。每个响度版本给同一份混音分别请求两张嘴，四次都选对才算成功。RoomReader 与 EasyCom 的有声结果用同步个人音轨评分。RoomReader 三人和弱目标原混音 SI-SDR 分别是 −7.23 和 −9.05 dB。MISP 这场没有同步个人参考波形，只报告静默和换嘴响应。静默泄漏越负越好。

| 指标 | 基础自然 | 基础增强 | 新结构自然 | 新结构增强 |
|---|---:|---:|---:|---:|
| LRS2 同混音 ±12 dB 双极性成功 | 23/32 | 21/32 | 20/32 | 24/32 |
| LRS2 受控三人双向正确 | 22/32 | 24/32 | 25/32 | 27/32 |
| LRS2 合成静默泄漏 | −14.46 dB | −16.70 dB | −12.42 dB | −19.10 dB |
| RoomReader 真实三人，12 段 SI-SDR | −9.27 dB | −5.48 dB | −8.34 dB | −7.80 dB |
| RoomReader 真实弱目标，12 段 SI-SDR | −12.49 dB | −12.10 dB | −15.28 dB | −9.63 dB |
| RoomReader 可见静默，11 段泄漏均值 | −25.96 dB | −18.66 dB | −22.79 dB | −18.86 dB |
| RoomReader 静默最坏一段 | −8.53 dB | −3.93 dB | −3.63 dB | −3.75 dB |
| EasyCom 同室真实重叠，8 段 SI-SDRi | +0.78 dB | +2.24 dB | +0.80 dB | +0.26 dB |
| EasyCom 可见静默，8 段泄漏均值 | −18.99 dB | −15.75 dB | −24.86 dB | −15.89 dB |
| MISP 可见静默，6 段泄漏均值 | −17.05 dB | −10.43 dB | −20.28 dB | −13.93 dB |

RoomReader 逐条混音、嘴图和可用状态与上轮一致，36 段中 35 段有效。EasyCom 16 段逐条重新核验混音、嘴图和参考轨哈希。MISP 六段真实重叠共 8.16 秒，在每段内固定至少三人同时活动，六段静默共 8.4 秒。

## 各项变化贡献

| 指标 | 原结构加数据 | 新结构加数据 | 自然数据加结构 | 增强数据加结构 |
|---|---:|---:|---:|---:|
| LRS2 ±12 dB 双极性成功，32 对 | −2 对 | +4 对 | −3 对 | +3 对 |
| RoomReader 三人 SI-SDR | +3.80 dB | +0.54 dB | +0.93 dB | −2.33 dB |
| RoomReader 弱目标 SI-SDR | +0.39 dB | +5.65 dB | −2.79 dB | +2.47 dB |
| RoomReader 可见静默泄漏 | +7.30 dB | +3.93 dB | +3.17 dB | −0.20 dB |
| EasyCom 三人以上 SI-SDRi | +1.47 dB | −0.54 dB | +0.03 dB | −1.98 dB |
| EasyCom 可见静默泄漏 | +3.24 dB | +8.97 dB | −5.87 dB | −0.14 dB |
| MISP 可见静默泄漏 | +6.62 dB | +6.36 dB | −3.23 dB | −3.50 dB |

受控弱目标里，±12 dB 的差中差为 +6/32（+18.75 个百分点，按混音配对重抽区间约 +6.25 至 +34.38 个百分点）。效果随数据配方而变。RoomReader 弱目标差中差 +5.26 dB，按会话重抽区间约 −6.99 至 +14.99 dB。这一组四臂平均 SI-SDR 均低于原混音。RoomReader 三人目标拟合分量胜过最大干扰的数为 6／8／6／7。MISP 新结构自然组换嘴波形差相对两输出平均能量为 −0.12 dB，基础自然为 −1.59 dB，表示响应增大。缺独立近讲波形，该值无法证明输出归属。

三套真实资料在两种结构上都出现增强数据加重平均静默泄漏，与合成静默改善的方向相反。24 个置零块来自 11 个低活动窗口，且增强组同时替换了 192 个响度槽位。下一次应先把响度增强与可见静默分别开关，用独立的有真实静默标注的训练数据，拉长静默段并保留说话边界。然后以自然响度和独说保真、真实重叠、最差静默共同筛选。该频带分支可留作对照，当前结果不支持默认替换或启动长训。

## 处理耗时

两组增强臂用最终权重、同一 LRS2 循环输入、CPU 四线程、交叉顺序计时各 100 个实际推理块。累计每个块所需的 push 处理时间，基础结构 P50／P99 为 244.63／349.13 ms，新结构为 239.38／357.92 ms，两组全部超过 120 ms。测量期间有并行负载，计时不含采集与播放，不能据中位差判断新增分支加速。逐块记录与权重摘要位于 `factorial_followup/latency/trained_augmented_cpu.json`。
