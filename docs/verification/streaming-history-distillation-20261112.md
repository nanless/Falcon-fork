# RealSSA-Sim 120 ms 流式改进阶段验证

本轮从旧完整训练的第 114 轮权重出发。旧模型在官方 TT 的 9,166 条有效样本上平均 SI-SDRi 为 4.256 dB，发布 Falcon 为 7.731 dB。两个模型读取相同的 ch0、中心 2 秒音频和嘴图。流式模型输出每个 120 ms 块，发布模型一次处理整段。训练结束及完整旧评测见 [第 111、114、136 轮测试](streaming-120ms-realssa-tt-epoch111.md)。

## 拆开历史、合成头和视觉条件

在固定种子 20261113 抽取的 24 条派生开发样本上，对每个 120 ms 输出块分别做五种推理。滚动前缀把当前块及之前的全部观测输入发布模型，再裁出当前块输出。固定 2 秒零未来保留模型输入尺寸，将块后的音频与已归一化嘴图填零。独立块每次重置全部上下文。所有输出拼成整段后计算同一 SI-SDRi。

| 推理条件 | 平均 SI-SDRi |
|---|---:|
| 发布 Falcon，完整 2 秒 | 7.814 dB |
| 发布 Falcon，滚动前缀 | 7.019 dB |
| 发布 Falcon，固定 2 秒零填未来 | 5.861 dB |
| 发布 Falcon，独立 120 ms 块 | 2.854 dB |
| 旧流式 v4，120 ms 块和历史状态 | 5.070 dB |

滚动前缀与 v4 都在当前块结束时取得真实输入，前者高 1.950 dB。它每块重新运行增长中的前缀，且其结构、预训练和历史长度均不同。该实验提示块间因果条件仍有可利用的历史信息，具体贡献须由相同主干的训练对照估计。

对同 24 条另做逐跳合成 oracle。冻结混音输入和 129 抽头因果 FIR 变换，允许优化器读取干净目标、直接求每跳频响。非负系数从 0.25 起步，有符号系数从 0 起步，两组都对正、负目标极性各做 1,200 步并取分数较高的一支。非负锥的平均 SI-SDRi 为 15.336 dB，有符号无界系数为 28.207 dB。非负锥允许大于 1 的系数，但每段可以按一个统一正比例缩放到 [0,1]，SI-SDRi 在忽略数值稳定项时不变。这个实验衡量表达能力，使用了部署时不可获得的目标和整段信息。有符号解的幅度可能偏大，需要通过真实训练和输出幅度检查验证。

发布权重、旧流式第 114 轮和独立预训练 FRCNN 的 137 个视觉骨干张量逐个完全相同。另从派生开发集抽取 128 条，在各自原前端输出后扰动特征时间顺序。

| 视觉特征 | 旧流式 v4 | 发布 Falcon |
|---|---:|---:|
| 原对齐 | 4.987 dB | 7.768 dB |
| 倒序 | 1.224 dB | −0.595 dB |
| 循环平移 480 ms | 0.373 dB | −3.028 dB |
| 整段平均后各帧相同 | 2.079 dB | −14.844 dB |

两者都依赖正确的嘴部运动时间关系。发布模型在这批样本上对时间扰动更敏感。输入语义和视听融合存在差异，骨干张量相同。对每卡 batch 64 的纯视觉基准，解冻 ResNet 第四阶段令视觉前反向中位数从 296.79 ms 增至 542.55 ms，本轮短训保留冻结骨干。

## 教师参考和固定训练视图

发布 Falcon 的视频 LSTM 在默认实现中把张量首轴解释为序列轴。直接以 batch=16 推理的输出对逐样本 B1 参考最大绝对误差为 0.011708。教师包装器把每条视频的每帧放入互相独立的长度 1 序列，保留发布模型 B1 时的行为。32 条真实训练样本的 A800 探针中，包装后 microbatch=1 的最大误差为 1.19e-7，microbatch=16 为 0.000262，最大 RMS 误差为 2.20e-5。microbatch=32 误差明显增加，生成缓存采用 16。证据是服务器 `/root/group-shared/voiceprint/experiments/falcon_teacher_probe_20261112.FroPhl/result.json` 和 `precision.log`。

缓存使用训练集的第 0 轮确定性随机裁剪、空间裁剪和水平翻转，每条存 32,000 点 FP32 教师输出。缓存和对应对照组均固定这一视图，每轮仍重新打乱样本次序。分片记录索引、教师权重、代码指纹、样本覆盖及文件摘要，核验后才发布清单。37 条真实样本双分片试验通过覆盖和文件摘要核验，分片边界与末尾 9 个抽查样本对在线参考的最大绝对误差不超过 0.000200。完整训练缓存已核验，两个分片覆盖 80,205 条。另固定抽查 263 条，覆盖首尾及分片交界，检查样本身份和固定视图，其中 253 条通过教师门槛，入选样本平均教师 SI-SDRi 为 7.758 dB。清单 SHA-256 为 `7550361f6c7c0149dd42d33795fb94114d301bb8b2867480e75cabd2a0e2f2c8`。复核见本轮实验目录的 `teacher-cache-verify.log` 和 `teacher-cache-sample-audit.json`。

## CPU 验收与因果复核

[单块计时工具](../../tools/streaming/bench_cpu_review.py) 的设置为 `--budget-ms 60 --paced --threads 4 --warmup 20 --chunks 500`。计时从预裁嘴图和对应 1,920 点音频交给会话开始，包含裁剪归一化、视听模型、状态更新和输出复制。采集、检测跟踪、网络及播放另计。输入是一条真实 LRS2 片段的 16 个完整块循环。处理耗时与计划释放到完成分别统计。

双卡 2 步 v6 冒烟权重的处理 P99 为 23.80 ms，最大 24.71 ms。v7 并发负载下两次绑核测试出现单块超限。固定核 24–27 的强开门控 v7 处理 P99 53.38 ms、最大 170.19 ms，500 块中 5 块达到或超过 60 ms。固定核 20–23 的实测 P99 58.32 ms、最大 94.33 ms，500 块中 4 块达到或超过 60 ms。并发测量见 [v7 架构探针](streaming-v7-architecture-probes.md) 和本轮实验目录的 `v7-active-affinity20-23.json`。
