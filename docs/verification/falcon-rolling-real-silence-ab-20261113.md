# 流式 Falcon 响度反事实与真实可见静默短训

2026-11-13，A800 GPU 1，PyTorch 2.8.0+cu128，FP32，关闭 TF32。四组使用相同的 Falcon Small 发布初始化和滚动分离结构。给定混合音频及目标嘴图，每次输出一路目标波形。固定 600 ms 历史、120 ms 输出、80 ms 前视。

## 四组的变量

| 权重标签 | LRS2 响度增强 | 真实可见静默监督 |
| --- | --- | --- |
| level_off_silence_off | 关闭 | 关闭 |
| level_on_silence_off | 开启 | 关闭 |
| level_off_silence_on | 关闭 | 开启 |
| level_on_silence_on | 开启 | 开启 |

四组均用发布 epoch 714 的音频路径、相同冻结 FRCNN、相同冻结 BatchNorm 统计。每臂 96 次 AdamW 更新，学习率 0.0003，固定梯度范数裁剪 5。每步共八行，合计每臂 768 个训练方向。每隔四步把最后一个两方向 LRS2 槽替换为同一真实目标的两个 120 ms 请求，一个可见静默，一个有声。其余槽来自上轮冻结的同一 LRS2 tr 120 混音索引和配对顺序。四臂共用 192 个响度实验槽、168 个自然槽、24 个真实槽。CV32 留出清单沿用上轮。

- 响度开启时只重混指定的 192 个 LRS2 槽，按整段 RMS 构造 s0 对 s1 为 0、±6、±12 dB 的响度差。每个槽的两次目标请求共享同一重混波形。关闭时这些槽使用原始混音和原始目标。两臂的嘴图及计分窗相同。
- 静默开关只作用于 24 个真实可见静默请求。四臂在这些窗都执行前向且均分母保持为 8。关时该行梯度为零，开时以零波形为监督，损失是 `10 log10(1 + 输出功率 / 混音功率)`。四臂均记录该损失作为诊断。相同真实目标的有声保护用同一个人音轨，不受静默开关影响。
- 用 26 个已检查 RoomReader episode 做可用库，24 个训练槽轮转覆盖五个会话、14 位目标人物。训练会话与盲评会话排除交集，共用老师禁止进入目标，且在所选训练窗须无标注语音并通过相对混音能量检查。用于训练的真实音频是原始发行混音。数据入场条件详见训练准备记录。
- 24 个有声保护窗中，12 个在对应静默块之后 240 至 1,080 ms，12 个在其之前 240 至 840 ms。相对训练有声掩码连续区间起点，13 个有声评分块偏移不超过 80 ms。该监督保护同一目标的有声段，实际重新开口应以独立盲评为准。

双向正确指两次目标请求的输出都更接近各自目标。自然响度两次请求共享相同波形。弱目标列的混音分别让所请求目标较轻。双极性列要求 +dB 和 −dB 两个共享混音的四个请求都正确。

在该短预算，响度增强提高两种静默设置下的弱 12 dB 及三人双向计数。固定响度设置打开真实静默监督，LRS2 合成静默泄漏分别升高 2.93 和 1.81 dB，同时独说保真分别提高 1.80 和 3.25 dB。合成静默用原本包含说话运动的嘴图配静音目标轨，真实可见静默采用真实同场停口，两项应分别记录。
