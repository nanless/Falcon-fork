# 120 ms 流式子带估计扩容验证

本轮保留每次 1,920 点音频、3 张嘴图和 1,920 点输出的块接口。模型收到当前 120 ms 块后可以在块内使用任意位置的信息。跨块状态只保存已经处理过的输入与特征。CPU 验收用 4 个线程按实时节奏处理 500 块，从预裁嘴图与对应音频开始计时，包含嘴图归一化、推理、状态更新及输出复制。

## 容量和训练信号

v9 在已训练的 v8 子带估计器旁增加一个局部时频分支，复用压缩复谱输入，用多种时频膨胀率覆盖相邻频带及整块内的时间位置。可训练的嘴图调制参与各频带估计。零初始化输出投影让新分支在热启动时输出零增量。宽度 64、深度 4 的候选新增 118,408 个参数，宽度 96、深度 6 新增 272,264 个参数。两种候选均保留旧主干的 320 通道和历史状态定义。

三个短跑从 v8 第 1 轮第 626 步权重热启动，均用双 A800、每卡 64 条、同一随机种子与采样顺序，执行 200 次更新。派生训练和验证索引来自 RealSSA-Sim 官方训练集，目标母视频目录隔离，旧权重此前接触过这些来源。模型选点使用完整派生验证集的原重建指标。短跑的 512 条开发样本用于观察候选表现。

| 配方 | 额外时频分支 | 学习率 |
| --- | --- | --- |
| 小模型对照 | v8 原有估计器 | 主干及子带层 3e-5 |
| 扩容 64×4 | 64 通道、4 层 | 旧参数 3e-5，新分支 9e-5 |
| 扩容 96×6 | 96 通道、6 层 | 旧参数 3e-5，新分支 9e-5 |

三组均沿用按轮变化的时间裁剪和嘴图增强，保留原训练 SI-SDR 软下限和多分辨率复数谱损失，加入权重 0.25 的局部重建辅助项。新增参数组的学习率随 100 步线性预热，严格续训会核对组学习率倍数、分支容量和辅助项的权重与源码摘要。参数组探针验证了预热和一次减半调度均保持 3 倍比例，也验证了变更倍数的续训请求会被拒绝。扩容与新增参数组学习率共同构成待选训练配方。

局部重建用完整 480 ms 窗，每次移 120 ms。中心化目标 RMS 至少为 0.001，且目标相对混音功率比达到 −20 dB 的窗口参与计算。所有完整窗口进入固定分母。低能量和退化窗口返回零辅助损失，原重建及谱目标继续处理其适用样本。输出功率及投影、残差比的下限降低近正交或近完美时的梯度峰值。该项只在训练裁剪输出上计算。

对 32 条实际训练样本，用 v8 热启动权重复核了局部波形梯度。局部损失梯度范数的中位数、P95 和最大值为 3.19、10.12 和 37.27。加权后与全局软 SI-SDR 梯度范数的逐条比值，中位数为 30.4%，P95 为 67.1%。此前两个已知产生高梯度的弱目标分别有 0/13 个局部窗口入选。局部损失五个定向测试覆盖可靠性分母、静音零梯度、近正交、低输出能量和完整窗口边界。

## 热启动、因果性与 CPU

真实输入验证中，两种扩容在零输出初始化后与 v8 波形逐采样一致。独立激活扩容输出层后，分别扰动后续块的音频和嘴图，已完成输出的前缀最大差值仍为 0。测试脚本和权重摘要位于实验目录的 `architecture-bench/real-migration.json`。

| 初始化权重 | 4 线程 CPU P99 | 500 块最大值 | 达到 60 ms |
| --- | ---: | ---: | ---: |
| 扩容 64×4 | 36.35 ms | 42.23 ms | 0 |
| 扩容 96×6 | 33.61 ms | 37.03 ms | 0 |

完成 200 步后，以对应的实际权重复测。两组均在同一服务器 4 个 CPU 线程上按实时节奏处理 500 块。

| 200 步权重 | CPU P99 | 500 块最大值 | 达到 60 ms | 跨块前缀最大差值 |
| --- | ---: | ---: | ---: | ---: |
| 扩容 64×4 | 33.24 ms | 36.44 ms | 0 | 0 |
| 扩容 96×6 | 32.15 ms | 37.16 ms | 0 | 0 |

64×4 的真实双卡权重从第 200 步严格续训至第 202 步成功。

## 质量目标与评估

同一派生开发集 512 条全部通过配对核对，按目标视频目录分成 210 组。开发集使用原 2 秒中心裁剪评测。

| 权重或配方 | 平均 SI-SDRi |
| --- | ---: |
| v8 热启动起点 | 5.02888 dB |
| 小模型对照 | 5.03563 dB |
| 扩容 64×4 | 5.03604 dB |
| 扩容 96×6 | 5.03374 dB |
| 同批发布 Falcon | 7.97192 dB |

64×4 相对小模型对照的逐条配对均值为 +0.000410 dB，目标视频目录重采样的 95% 区间为 [−0.000670, +0.001687] dB；相对起点为 +0.007158 dB，区间 [−0.008786, +0.024874] dB。32 条开发样本的独立消融中，仅关闭已训练新增分支，64×4 和 96×6 的波形相对 RMS 差中位数分别为 0.445% 和 0.587%。64×4 作为正式配方，理由是其短跑分数在两个扩容候选中最高，新增参数和计算量均更小。200 步的配对差异很小，尚无扩容能提升分离质量的证据。

完整训练使用 10,828 条派生验证集选点。v9 从同一个 v8 检查点热启动，由隔离仓库运行。原仓库中的 v8 训练继续使用它自己的配置和代码。

论文报告的 RealSSA-Sim 首通道目标为 **7.7 dB SI-SNRi、8.2 dB SDRi**。新增整句评估入口 `tools.streaming.evaluate_realssa_utterance` 从官方 TAR 读取首麦克风通道，按音频与 25 fps 嘴图共同有效区间对齐。开源权重按整句执行，新模型依次输出 120 ms 块，尾部补齐后的输出裁回有效长度，汇报两项指标及样本覆盖。论文明确使用首通道，本地固定为整句及 512 抽头 SDR，另以发布权重在同一脚本中给出实测配对参考。论文未披露 RealSSA-Sim 测试裁剪和 SDR 滤波长度。[Falcon 论文](https://arxiv.org/html/2610.32749v1)验证阶段的开发指标和这套整句测试分别记录。

64×4 的 200 步权重在 3 条真实官方 CV 整句样本上完成两项指标的有效配对。正式训练结束后，脚本会按完整验证损失选点，复测因果与 CPU 耗时，再对官方 TT 运行两个分片并核验覆盖后合并。论文目标是否达到取决于这份最终整句报告。

产物位于服务器 `/root/group-shared/voiceprint/experiments/falcon_streaming_v9_capacity_20261112/`。短跑入口 `run_sweep.sh`，配对审计 `paired-sweep.json`，正式启动 `run_full.sh`，训练结束后的评估脚本 `post_train.sh`，局部梯度抽查 `probe-local-loss.json`，参数组证据 `lr-group-audit.log`，短跑新增分支消融 `probe-capacity-ablation.json`，整句评估冒烟位于 `utterance-eval-check/`。模型配置见 [RealSSAStreamingCapacity.yml](../../configs/RealSSAStreamingCapacity.yml)。
