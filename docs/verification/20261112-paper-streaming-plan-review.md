# 论文与 120 ms 流式训练候选方案复核

日期：2026-11-12。论文：[Efficient Streaming Audio-Visual Target Speaker Extraction for Real-World Acoustic Scenes](https://arxiv.org/html/2610.32749v1)，重点为第 4、5、6 节和附录 D、K。这里比较论文、发布代码和当前尚未启动的 `configs/RealSSAStreamingScratchBatch1024.yml` 候选配置。候选是新模型，不是只改变流式时序的原 Falcon。复核结论：现有方案尚不足以支撑达到论文效果的判断，需要继续解决架构、训练目标和数据协议差异。

## 先固定用户要求

120 ms chunk；块内可双向查看，块间只能使用历史；CPU 单块处理低于 60 ms；两卡、每卡 batch 1024、每次直接更新、不做梯度累积；音频、融合及分离部分从零初始化；预训练 FRCNN 保持冻结；实验产物放在 `/root/group-shared/voiceprint/experiments/`。0.01 和 0.1 是需要验证的学习率候选，充分预热后仍需检查实际训练稳定性和验证表现。

## 逐项对照

| 项目 | 论文 / 发布代码 | 候选配置 / 结论 |
| --- | --- | --- |
| FRCNN 初始化 | 唇读预训练，AVTSE 全程冻结 | 加载 `frcnn_128_512.backbone.pth.tar` 并冻结；它从公开 `falcon.pt` epoch 714 提取，SHA256 为 `980339a9351cef0cdc39ea6e1257c59681ceac813f6e091178de5d1afcfd93bd`。其与原始独立唇读文件身份尚未单独核实。不能随机初始化并声称对齐论文。 |
| 其他初始化 | 论文未明确逐参数披露音频初始化 | 用户要求音频、融合、分离从零；首次启动不得加载已有流式分离模型或教师，resume 必须为空。保存初始化身份和视觉参数冻结证据。 |
| 视频时间 | 发布 FRCNN 时间核长 5、左右各 2 帧；论文报告视觉分支固定 120 ms 前视 | 当前 `causal` 将时间核改为 4 帧历史加当前帧，相比对称核时间语义改变；两帧为 80 ms，仅指该卷积层，不能等同论文整个视觉分支延时。应比较块内居中方案与当前方案，并证明不读取后续块。 |
| 视觉融合 | 论文描述视频 LSTM；发布代码默认 LSTM 维度行为与论文描述有差异 | 当前使用投影和块内注意力，没有原 VideoBlock LSTM。发布代码默认 LSTM 将输入批次维当作序列维，应分别验证论文意图与公开实现，避免继承跨样本混合。 |
| 视频预处理 | 论文 96×96 嘴部区域；原实现训练随机裁、验证中心裁为 88×88 | 88×88 模型输入本身符合原代码；训练翻转、裁剪和帧对齐仍应按相同输入逐项比较。 |
| 音频与分离器 | 256 点 Hann STFT、hop 128，实部/虚部/幅值输入，多尺度时频分离、复数掩码、解码器 | 当前是单尺度逐帧卷积、块内注意力、子带支路和因果 FIR。是大幅度架构替换，不能等同论文。论文复数掩码比实数掩码高 0.4 dB 的消融结果不能直接当成本模型的预计收益。 |
| 回看 | 论文的具体时频网络与当前不同 | 候选注意力 `attention_history_chunks: 0`，不直接回看前块；主干膨胀卷积有历史状态，约 1.016 s 的主干有效历史需结合具体输入输出时钟检验。 |
| 损失 | 负 SI-SNR + 权重 1 的编码空间对比损失；逐个近场干扰源为负样本，margin 0.5，负样本加权温度在前 1000 epoch 从 0 到 1 | 当前 `reconstruction_only: true`，另加权重 1 的谱损失、0.25 的局部损失及重建 floor，没有论文的对比项。这是重要差异；论文对应消融显示 Falcon 提高约 0.4 dB，不能把该差值直接套用于新架构。 |
| 近场监督 | 需要各个近场干扰源在混音时间轴对齐的波形 | 已下载 TAR 样本含 mix、target、mouth、metadata，不能把 mix-target 当成单独某个近场说话人。发布代码按 metadata 原始路径读取近场干声音频，并不在读取时施加 RIR；服务器发现部分 LibriSpeech 原始归档，仍需验证文件覆盖率和原混响重建所需信息。发布代码干声口径与论文描述的混响逐源波形须分开记录。 |
| 数据划分 | 官方 RealSSA-Sim tr/cv/tt 为 100826/9133/9169 | 审查时原候选训练/验证是官方 tr 内额外按源分组派生的 80205/10828 条，与官方协议不同。现已将候选配置切换至官方 tr/cv，官方 tt 用于最终测试；派生划分可作为额外泛化检查。官方不同 split 存在部分源路径重叠，不能表述为严格源隔离。 |
| 采样 | 发布代码默认每 epoch 有放回抽 10000 次；论文实际运行 epoch 抽样长度未披露 | 候选为分布式洗牌、近似无放回；以 80205 条和全局 batch 2048 为例，每 epoch 39 次更新。不同 epoch 不能直接比较。 |
| 优化器 | AdamW、LR 0.001、weight decay 0.01；8 卡每卡 4 | 候选 AdamW、目标 LR 0.01、weight decay 0.01；2 卡每卡 1024、无累积。用户要求的大 batch 保持不变；学习率需要实际验证，不可仅从 batch 比例断言。 |
| 调度和停止 | ReduceLROnPlateau patience 15、early stop 30、最大 1000 epoch；1000 epoch 指对比温度变化，并非学习率预热 | 候选 LR 预热 1000 更新、plateau patience 5、早停 25、最多 300 epoch。这些是新设定；当前派生训练集下预热约 25.6 epoch。按实际 optimizer step、数据暴露和验证曲线检查，不预先承诺收敛。 |
| 分块与长度 | 论文训练为 2 s、16 kHz、25 fps | 当前 2 s 补齐至 17×120 ms，再裁回 2 s；需验证尾块训练和推理一致，并做未来块扰动不变测试。 |
| 实时性 | 论文与此处 CPU 基准不是相同测量协议 | 已有候选在特定 CPU、线程及输入条件下的 500 块实测最大值约 36–37 ms；这是该次测量，不是任意负载下的保证。新架构或时间对齐方式变化后须重新测量。 |
| 指标与结论 | 论文 RealSSA-Sim 报告 SI-SNRi / SDRi；公开权重与论文 checkpoint 是否完全相同尚未确定 | 应在官方 tt、相同通道、输入裁剪和指标下逐样本配对；区分完整测试与小样本探针。短试验不能证明收敛或达到论文效果。 |

## 后续验证顺序

1. 首先完成近场独立波形及可重建性的资产审计；不能可靠获得时，将缺项写入实际目标，不伪造负样本。
2. 主训练与对照采用官方 tr/cv/tt，并保留原官方分割源重叠事实；派生划分单列。
3. 设计更接近论文多尺度、复数频域输出的块因果结构，同时逐项验证视觉时间对齐、跨块状态及 CPU 成本；不能把当前模型参数量当作效果证据。
4. 对初始化执行检查：视觉与提取权重一致且不更新，音频和分离器未加载旧权重，优化器只含可训练参数。两卡实测每卡 1024、无累积。
5. 以实际更新数评估学习率预热、梯度范数、非有限值、验证集曲线和不同配置；所有训练及评测数据写入 experiments。
6. 对确定的候选进行全量因果性、流式一致性、CPU 时延与真实数据训练测试，再进行正式训练；并保留可追溯的配置、代码、初始状态、日志和评测结果。

当前没有证据证明现有候选可达到论文质量，正式训练不应在这些关键方案差异尚未厘清时启动。
