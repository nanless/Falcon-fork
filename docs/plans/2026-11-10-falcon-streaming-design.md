# Falcon 音视频增量流式设计

目标是在 16 kHz 音频、25 fps 嘴部视频下，每 160 ms 输入 2560 个音频采样和 4 张嘴部图像，输出 2560 个采样，输出块无额外保护区。新模型使用随机初始化权重验证训练和推理，分离质量通过后续训练评估。

方案比较：保留 2 秒滑窗并缩短步长可以快速复用发布权重，但会重复计算，窗口尾部与全窗统计仍有未来依赖；使用原模块逐层实现缓存并重新设计全部归一化能够最大程度保留架构，但改造面大；本次采用 Falcon 派生的新模型，保留 FRCNN 嘴部前端、256 点频谱分析与视觉条件融合，使用因果缓存和可训练频谱掩码完成增量推理。该模型与发布权重结构不同。

视觉 3D 卷积使用过去 4 帧缓存，不读取后续帧；固定批归一化统计避免训练时跨时间泄漏。每个嘴部帧必须在其对应 40 ms 音频区间的起点已可用，部署侧需依据采集时钟选取历史帧。音频使用 128 采样步长的块处理和历史输入缓存，增量状态按会话独立保存并在目标切换或流结束时清理。模型每个 8 ms 音频步需等到该步采样到齐，160 ms 对外输出块需等整块到齐；没有额外右侧保护区不等于零成帧等待。

训练和推理共用模型分块接口；训练读取现有混音、目标语音及对齐嘴部序列，支持随机样本检查和 checkpoint 保存。验证包含未来扰动、跨块一致性、重置和会话隔离、视觉条件敏感性、训练梯度、真实数据读取、A800 延迟与长流连续性。端到端 300 ms 的验收需明确起止时刻，分别报告模型计算与含采集、视频追踪和播放的实际链路；随机权重不评价提取质量。
