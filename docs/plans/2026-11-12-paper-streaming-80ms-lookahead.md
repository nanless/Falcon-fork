# 120 ms 输出、80 ms 音视频前视的论文风格流式模型

## 目标和时间定义

16 kHz 音频，25 fps 视频。第 k 次调用输出 [120k,120(k+1)) ms 音频，可读取原始音视频最晚至块结束后 80 ms；所有层共享这一总前视预算。边界按样本区间和视频帧时间戳验收，网络传输时间不计入。CPU 测量以单路连续流每次处理 120 ms 输出的前向调用为单位，目标在实际测试中最大值低于 60 ms；记录设备、线程、预热、样本数和 p50/p95/p99/max。收集当前块和前视产生的等待不计入 CPU 计算耗时，端到端算法等待需要单独报告。

每次缓存只提交当前 120 ms 对应的状态；80 ms 前视不可提前写入持久状态，以免下一次重复推进。波形重建缓存、特征缓存、循环状态和归一化必须符合这个边界。流末尾用明确方式补齐并只输出有效采样。改变 80 ms 以后的输入不得改变当前块输出。

## 保留论文设计

使用论文的时频编码、频率多尺度与跨尺度连接、时频分离及复数掩码作为设计依据，以计算预算为约束做流式改造。冻结唇读预训练 FRCNN，使用其原有对称 5 帧时间卷积：前 2 帧历史 + 当前 3 帧 + 后 2 帧得到当前 3 帧特征。后 2 帧的视觉特征如果再通过同一居中 FRCNN 计算，将需要额外视频前视，不能混入当前块。音频侧允许访问块后的 80 ms，但任何 STFT、归一化、卷积、注意力和重建都不能突破总预算。

历史尽可能长：循环或缓存状态只依赖历史，针对时间卷积使用可配置感受野；实际长度、显存、性能均须测定。每次在 60 ms CPU 预算内比较不同宽度、深度、历史和模型大小，而不是仅凭参数量判断质量。

## 数据与训练

使用 RealSSA-Sim 官方 tr/cv/tt 索引，分别为 100826、9133、9169 样本；主训练、模型选择和最终测试各用相应划分。音频、融合和分离器从零初始化，不加载旧分离模型；视觉骨干加载已核实的发布模型提取权重并冻结。两张 A800，每卡 batch 1024，不做梯度累积，AdamW 较大学习率并预热；先验证显存、数值稳定性、实际目标学习率和完整验证集曲线。训练损失以真实可用的波形重建为基准，对可用频谱、局部及正样本对比进行明示和对照；不可把混音残差假称逐人近场真值。实验配置、日志和产物仅存 experiments。

## 必做验证

1. 原 FRCNN 完整序列与分块视觉特征逐帧相等；正确检查首尾填充和冻结权重。
2. 音视频对齐、跨块状态、重置、短尾补齐和长流测试，比较同一输入的离线展开与逐块执行。
3. 扰动允许前视以后所有音视频，当前块输出不变；改变预算内的数据能影响输出。检查不同序列与 batch 不串扰。
4. STFT / iSTFT 或等价重建精确对齐并覆盖边界，确保无隐含额外前视，输出长度正确、梯度有效。
5. 两卡真实数据、每卡 1024、accum=1 的显存和更新验证；确认仅视觉使用预训练，达到指定学习率后再分析数值稳定性。
6. 真实 CPU 连续流测速，按预算选大模型；官方测试集上与公开模型同输入同指标逐条对照，并记录整个协议。
