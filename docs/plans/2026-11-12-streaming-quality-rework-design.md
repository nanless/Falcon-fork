# 120 ms 流式模型质量修复：设计和验证

## 目标与边界

保留原有 120 ms 块间因果性和零保护区，CPU 完整块处理目标小于 40 ms；用户要求的双卡每卡 batch 1024 不作梯度累积。正在运行的 v4 原试验和源代码保持不变，本轮使用独立 checkout 和 `/root/group-shared/voiceprint/experiments/falcon_quality_rework_20261112/` 下的新实验。每个实验保存实际配置、源代码与数据摘要、权重来源、训练和评测日志。

## 设计选择

1. 静音处理：分别计算正常目标的负 SI-SDR 与静音目标的输出能量惩罚，阈值和权重写入配置；验证记录有效语音/静音数量及各自指标。比较继续使用原公式和分支损失，不能将不同损失的数值当作直接提升。
2. 对比头：原公式保留为对照，并把全无负样本分支向量化；不把不同视频目录未经身份核验地当作不同说话人。候选使用可开关的防表征集中正则或冻结教师，必须报告计算定义、信息来源和异常条件。训练前后记录相同候选集的配对排名、表征分布和分离质量。
3. 视觉时序：保留 v4 因果视觉前端，另试验只使用历史和当前块三帧、在当前块末复制边界的居中前端。新语义和检查点明确区分，不把旧检查点直接视为严格续训；网络兼容参数可经显式 warm-start 初始化并记录来源。对照须训练适配，推理直接替换只能作探针。
4. 验证与检查点：分别保存数值最低验证检查点和用于早停的最小改善判断状态；严格续训应验证数据、模型、优化器和协议身份。旧协议要明确区分，不能静默恢复。
5. 数据：官方 tr/cv/tt 保持原状作原协议比较。另从 tr 依据视频来源目录分组生成候选训练、开发和测试清单，确保该目录集合互不相交，未知来源单独处理；仅目标音频源与视频父目录按组隔离，混音中其他干扰或噪声源未检查，目录也不等于经过验证的说话人身份。现有 v4 检查点已经训练过完整官方 tr，因此基于该检查点 warm-start 的分组对照只能是见过源的干预诊断，不能宣称源未见；真正源隔离实验需从未接触该保留组的初始化开始，并说明外部视觉预训练来源。原官方 tt 已用于此前诊断，不作为新模型调参后的独立测试。

## 实验设计

优先验证针对性正确性：静音梯度、语音损失保持、向量化值和梯度、状态和恢复协议；视觉前端执行未来块扰动、块内互看、与单块/整段等价、尾块与检查点兼容测试。比较原始和新方案使用相同数据清单、种子、起始权重和优化预算；任何仅前向的模型切换须与重新训练区分。正式质量比较关注源组隔离开发集，明确测试条数和无效数，再以未用于迭代的新 held-out 样本验证。记录开源 Falcon 2 秒和流式模型 120 ms 上下文差异。

试验资源与时延先测：新模型全含视觉的 120 ms 单块 CPU 计时，记录训练并发、线程、P50/P95/P99/最大和超预算次数；双卡目标批量真实 forward/backward 和严格续训。训练进行中出现任何超时、非有限、内存不足或数据问题，保留日志并修复后重试；在验证曲线不足以支持收敛时如实标记实验阶段。

## 阶段

1. 独立复核训练损失、模型结构、数据/评测及历史证据；制定受控实现。
2. 修改隔离 checkout 中的模型、训练入口、配置和测试；逐项复核并运行回归。
3. 建立可复现分组清单，执行真数据小样本双卡 smoke、恢复、CPU 时延与因果验证。
4. 运行匹配预算的训练和质量对照，依完整验证选择检查点后进行保留测试。
5. 更新项目文档；经服务器仓库完成中文提交、推送并核对远端。原训练源码在其运行期间不被替换。
