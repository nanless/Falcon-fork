# v9 从零训练音频与分离网络

**状态：候选方案审查中，尚不作为正式训练方案。** 论文多尺度架构、近场对比损失及其他主要差异见 [论文对照复核](../verification/20261112-paper-streaming-plan-review.md)。

音频编码、视听融合和分离网络使用随机初始化。嘴部视觉编码使用预训练 FRCNN，并沿用冻结设置。训练不加载流式模型的热启动权重或教师；严格续训只接受同一从零训练产生的检查点。视觉批归一化运行统计固定，以保证因果计算。

每卡 batch 1024、两卡全局 2048，每个 batch 执行一次更新。训练时重算块的前向激活以控制显存，完整梯度用于同一次更新。目标学习率 0.01，1,000 次更新线性预热，两个优化器参数组采用相同学习率。完整验证沿用原重建指标选点。

先核对预训练视觉骨干、音频和分离网络随机初始化及优化器参数，再执行真实双卡显存和更新试跑。配置、检查点、日志和验证证据保存在 experiments。
