# RealSSA-Sim 块级流式模型训练设计

目标是在相同的真实 RealSSA-Sim 混音、目标语音、嘴部画面及对应通道上训练 160 ms 块级因果模型，提供双 GPU 训练、验证、恢复和推理链路。对照原模型时使用同一个数据索引、训练验证划分、通道与评测协议，记录不可完全一致的训练条件。

原始数据以 TAR 分片存放在共享冷端。先检查分片身份并建立样本偏移索引；训练直接随机读取 TAR 成员，避免无必要地复制全部音视频。训练片段为 2 秒/50 帧；新模型内部按 13 个 160 ms 块执行，最后 80 ms 补零并只计算前 2 秒的损失。视觉主干使用作者已发布 Falcon 权重中提取的 FRCNN 并冻结，来源以哈希和元信息记录。

论文的重建项采用项目现有负 SI-SNR 实现；优化器 AdamW、学习率 0.001、weight decay 0.01。两 GPU 各 batch 4、梯度累积4步时每次更新使用32个样本。发布 RealSSA-Sim 分片没有各近场干扰者独立波形，试训显式标记仅重建损失，不能声称对比损失和原作者训练完全一致；不将混音差值伪装为单个近场说话人。视觉缓存来源为发布 Falcon 模型而不是已核实的独立唇读预训练文件。

对齐与验证包括 TAR 索引完整性、分布式样本划分、训练和验证切分、固定时长对齐、初始视觉参数与冻结状态、双卡有效梯度、断点恢复、输出长度与数值、CPU 会话推理和日志/检查点身份。有限步数的试训用来检验流程，不代表收敛或证明质量超过原模型。
