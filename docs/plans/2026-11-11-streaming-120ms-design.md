# 120 ms 块级流式模型设计与验收

## 目标和选择

在 RealSSA-Sim 官方训练、验证和测试划分上训练与评测新的 120 ms 块级因果模型。每块接收 16 kHz 的 1920 个音频采样和 25 fps 的 3 帧嘴图，允许块内音视频互看，跨块只使用历史状态。2 秒训练音频和 50 帧嘴图补齐到 17 块后执行，损失只计算有效的 2 秒。保持没有额外保护区。

候选路线包括：保留现有宽度直接缩块；在相同视觉骨干与因果结构下增加音频通道宽度；或更换视觉骨干。优先选择第二种，在 CPU 完整音视频处理的稳定测量和双卡训练显存都达标的前提下选宽度；如不能同时达标，按实测选择较小宽度。模型结构与块长写入检查点，旧 160 ms 权重不可误当新结构载入。

## 训练与评估

使用两张 A800，每卡 batch 1024、累积步数 1。调度和早停基于完整验证集；记录每轮样本、更新次数、验证损失、学习率、最佳轮次及检查点，以完整验证集的长期停止改善而非少量训练步判定收敛。训练数据公开包没有各干扰人的独立近场波形，当前正项对比损失不等于论文完整对比损失。

最终使用未参与参数选择的官方 tt 进行完整评测，记录样本数、失败数、指标、输入、配置和权重哈希；同时保留公开 Falcon 的条件匹配对照，并清楚说明完整窗口和流式块之间的上下文差异。实验数据与产物保存在 `/root/group-shared/voiceprint/experiments/` 子目录。

## 关键验收

1. 逐块处理、整段处理一致；任意未来块变化不影响当前块；音视频对齐、状态重置、末块截断和检查点身份经测试验证。
2. CPU 基准覆盖视觉预处理、视觉骨干、音频分离和块状态处理；记录硬件、线程、预热、块数及中位数、P95、P99 和最大值，目标每个 120 ms 块处理时间小于 40 ms。
3. 真实双卡以目标批量完成训练和续训；持续完整验证与保存最佳检查点，确认实际收敛后开展官方测试。
4. 更新训练、推理、评测、配置与文档，并在服务器仓库提交推送。
