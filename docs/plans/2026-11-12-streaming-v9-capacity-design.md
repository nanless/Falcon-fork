# 120 ms 流式估计器扩容

目标是在 120 ms 输出块和块间因果条件下提升 RealSSA-Sim 分离质量。以同一 512 条开发集筛选配方，训练后用完整验证集选择检查点，再用官方测试集进行整句、首通道的论文协议对照。CPU 验收计入已预裁嘴图归一化、会话状态、推理和输出复制，四线程按实时节奏测试 500 块。

单独加宽主干需要调整旧模型的权重和归一化，复用开源整套时频模型超出此前的 CPU 预算。选择保留 v8 参数，在旁路加入更深的多尺度时频子带估计。新增输出投影从零起步，迁移前向可逐采样核对。候选宽度与深度为 64×4 和 96×6，独立测量分离效果与耗时。

训练保留每轮随机裁剪和响度相位谱损失，并用局部 480 ms 辅助目标给可见的语音区间提供更直接的分离梯度。新增分支使用较高学习率，主干保持低学习率。先复核训练目标、v8 兼容和因果边界，再对三个相同起点与更新预算的模型执行真实双卡短跑。正式运行使用选中的配方、完整派生验证和独立产物目录。
