# 120 ms 流式 Falcon 质量改造

目标是在 120 ms 单块接口和 CPU 处理时间低于 60 ms 的约束下提高分离质量。训练从旧完整训练的数值最佳权重起步。验证集用于选择检查点，官方测试集用于同协议结果比较。

旧合成头使用非负频域系数构造自适应因果 FIR。候选保留原滤波支路，叠加同维度的有符号响应。新增支路从零初始化，首次更新前保持原模型输出。直接预测波形和多尺度解码器也是可选方向，本轮先测改动较小的滤波方案。

冻结开源教师对当批训练输入生成参考，按其对干净目标的预测质量筛选样本。干净目标始终参与重建训练。教师仅在训练端使用。对照组共享起点和数据协议，分别测量解码头和教师的作用。

完整训练前验证旧检查点兼容、前缀因果、真实双卡更新和 CPU 120 ms 块计时。训练运行到早停或配置上限，选点后全量评测并核对样本覆盖、有效分母和逐条结果。权重、明细和日志保存在服务器 experiments 子目录。
